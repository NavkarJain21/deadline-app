# Due Today
Features include:

- Create, edit, complete, and remove deadlines
- Due today, next 7 days, overdue, and completed views
- Search and sorting by urgency, date, or priority
- Dashboard statistics and keyboard shortcuts (`N` for a new deadline, `/` to search)
- Browser-local storage, so the list stays on the same device/browser

The first launch includes a few sample deadlines so the interface is immediately explorable. Remove them or replace them with your own.
